## 공통 흐름

페이지 머리말 다음에 결과 알림을 한 번 표시하고 본문을 놓습니다. 본문은 1200px 안에서 가로를 채웁니다. 구분선 섹션 사이는 40px(좁은 화면 32px), 폼의 범주 카드 사이는 16px(좁은 화면 12px)입니다. 각 부품의 실제 크기는 Foundations/Sizes와 Row grammar에서 확인합니다.

## 일곱 가지 틀

- [목록 L](?path=/story/templates-list--default): 머리말과 생성 동작 → 검색·필터 → Table. 항목 목록은 comfortable 44와 stacked 좁은 배치를 선택합니다. 빈 결과는 표의 spanning row이며 처음과 검색 결과 없음을 구별합니다.
- [상세 D](?path=/story/templates-detail--default): 돌아가기 링크 → 제목과 상태·메타 → 삭제·수정 → Facts 섹션 → 관련 표 → 실제 원문 CodePane. 한 열입니다.
- [설정 S](?path=/story/templates-settings--default): 머리말 → 결과 → Surface 안의 SettingRows·Facts·관련 표. 설정 요약은 범주 카드로 감싸지 않습니다.
- [생성·수정 F](?path=/story/templates-form--default): 머리말 → 연결된 오류 요약 → FormStack(안내 알림 먼저, 범주 Card) → 취소·저장 FormBar. 머리말에는 뒤로가기·취소가 없습니다. 리버스 프록시는 요약 레일·모바일 시트가 저장 바와 위쪽 오류 요약을 대신합니다.
- [모니터링·로그 M](?path=/story/templates-monitoring--spec): 머리말 → 결과 → KpiRow·Surface·한정된 로그 영역. 표본 없음과 일부 실패를 다르게 표시합니다. [개요](?path=/story/templates-overview--default)도 이 구성을 따릅니다.
- [인증 A](?path=/story/templates-auth--default): 가운데 360px 열의 마크 → 제목 → 비밀번호 폼 → 대체 로그인. 테마 전환과 버전 바닥글은 유지합니다.
- [예외 E](?path=/story/templates-exceptional--spec): ErrorView 계열은 실제 상태·오류 ID·다시 시도 동작을 표시합니다. 페이지 안의 차단 구역은 NodeErrorCard입니다.

[설정 적용 검토](?path=/story/templates-review--default)는 별도 페이지 틀이 아닌 Modal 검토 크기(760)의 사용 예입니다. 제목·본문·버튼 줄을 분리하고 본문만 스크롤하며 처리 중 모든 닫기 경로를 잠급니다.
